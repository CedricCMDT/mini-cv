# Mini-CV — Cédric Louvet

Mini-CV personnel développé dans le cadre d'un TP sur Git et GitHub.

## Présentation

Étudiant en Bachelor 3 Développement Applicatif à SUPDeVinci Bordeaux, en alternance chez Groupama.

## Technologies utilisées

- HTML5
- CSS3
- Git
- GitHub

## Installation

1. Cloner le dépôt :
   git clone https://github.com/CedricCMDT/mini-cv.git

2. Ouvrir le dossier `mini-cv`.
3. Ouvrir `index.html` dans un navigateur.

## Objectifs du TP

- Initialiser un dépôt Git.
- Utiliser les Conventional Commits.
- Gérer les fichiers ignorés.
- Synchroniser un dépôt local avec GitHub.
- Restaurer une ancienne version d'un fichier.
- Publier le site avec GitHub Pages.
